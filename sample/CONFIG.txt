# Tutorial entries for the load command in jsaleph/shell.js.
# Lines starting with # are comments outside entries.
# Lines starting with = are copied to tutorial.txt.
# <number> { <title> | <file> | <extra files> | <list note> | <console> }
#   <number>        1, 2, ...; also used in 'load <number>'
#   <title>         one line, shown in the list and when loading
#   <file>          the program, e.g. gcd.ale; the name without .ale is
#                   used in 'load <name>' and in the list
#   <files>         further files to load (modules, data), separated by
#                   spaces; they are not listed on their own
#   <list text>     shown under the title in the list (can be empty)
#   <console text>  printed to the console after loading
# Separate extra files with spaces. Escape |, } and \ as \|, \} and \\.
# Mind the files passed to a program: write  run wc {story.txt\} story.txt
# in the console text.
# The loader prints the title and file list, then the console section.

= ALEPH sample programs
=
= Load by number or name. Try
=       load 1         or         load hello
= Files are copied to the current project. Existing files are kept.
= The console shows how to open, compile, and run the sample. Enter
= each command separately. Programs which use modules must be compiled
= together with all of them. Edit the source for the fuller notes.
=
= For a first, quick tour of ALEPH, load these programs in this order:
=      hello, square, args, guard, stack, wc, sort
=
= I. First steps

1 { Print a greeting | hello.ale |  |
the smallest program, the warning pragmat |
Try:  Print a second line and inspect the compiler warning.
  edit hello.ale
  compile hello
  run hello
}

2 { Square an integer | square.ale |  |
reading numbers, a loop |
Try:  Enter 46340 and 46341. How can a square be negative?
  edit square.ale
  compile square
  run square
}

3 { Compute factorials | factorial.ale |  |

Try:  Enter 12 and 13. Compare the results with bignum (load 14).

}

4 { Print command-line arguments | args.ale |  |
