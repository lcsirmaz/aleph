# Tutorial entries for the load command in shell.js.
# Lines starting with # are comments outside entries.
# Lines starting with = are copied to tutorial.txt.
# <number> { <title> | <file> | <extra files> | <list note> | <console text> }
#   <number>        1, 2, ... consecutively; also used in 'load <number>'
#                   and in references such as "(load 14)"
#   <title>         one line, shown in the list and when loading
#   <file>          the program, e.g. gcd.ale; the name without .ale is
#                   used in 'load <name>' and in the list
#   <extra files>   further files to load (modules, data), separated by
#                   spaces; they are not listed on their own
#   <list note>     shown under the title in the list (can be empty)
#   <console text>  printed to the console after loading
# Escape |, } and \ as \|, \} and \\. Mind the files passed to a program:
# write  run wc {story.txt\} story.txt  in the console text.
# The loader prints the number, name and title, then the console text.

= ALEPH sample programs
=
= Load by number or name. Try
=       load 1         or         load hello
= Files are copied to the current project. Existing files are kept.
= The console shows how to open, compile, and run the sample. Enter
= each command separately. Programs which use modules must be compiled
= together with all of them. Most sources begin with a few comment
= lines which tell a little more.
=
= For a first, quick tour of ALEPH, load these programs in this order:
=      hello, square, args, guard, stack, wc, sort
=
= I. First steps

1 { Print a greeting | hello.ale |  |
the smallest program, the warning pragmat |
Try: Print a second line and inspect the compiler warning.
  edit hello.ale    (optional)
  compile hello
  run hello
}

  edit square.ale    (optional)

  run square
}
